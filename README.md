# О проекте:

Проект - это телеграм бот для наложения текста шрифтом Impact на картинки.
### Для того чтобы развернуть проект на свом устройстве вам понадобится
1. Установленный python
2. Скопировать репозиторий при помощи ```git clone git@github.com:Caductious/pallasAndApplesBot.git```
3. Инициализировать виртуальную среду
4. Установить необходимые библиотеки ```pip install -r requirements.txt```
5. Создать файл ```.env``` с содержанием ```BOT_TOKEN = <Ваш токен>```
6. Запустить файл app.py из корневой папки проекта
